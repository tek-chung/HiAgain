# Hi Again logos

- `hi-again-mark.png`, `hi-again-wordmark.png`: the original artwork (black on white).
- `hi-again-mark.svg`, `hi-again-wordmark.svg`: vector traces used by the app (`app/src/components/Logo.tsx`).

In the app the logos use `currentColor`: near-black `#1d1d1b` in light mode, `#f2f5f2` in dark mode (`--hs-logo` in `globals.css`).
Generated assets: `app/src/app/icon.svg`, `favicon.ico`, `apple-icon.png`, `opengraph-image.png`, and `app/public/icons/*.png`.
