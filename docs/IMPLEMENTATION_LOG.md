**Again, 13 November 2026:** Before building, asked Tek the two open lifecycle questions; Tek chose: either person can end a match (removed for both, no notification) and no expiry for one-sided Again. Added migration `20261113190000_again.sql`: sender-only readable signals, one match row per unordered pair, per-user match read receipts, and every change for a pair serialised with a transaction-scoped advisory lock. Interface: Again sits above the action cards (Again / Again ✓ “Only you can see your interest. Tap to undo.” / “It’s mutual.”), Coffee/Walk/Call with an editable copyable message (manual-copy fallback) and LinkedIn hand-off, no sending or booking, End match with inline confirmation; matches appear once in Activity as unread. Guests sign in first; the intent completes only when this browser recorded the tap, so a crafted `?resume=again` link cannot express interest. Evidence (cloud sandbox, fictional data): database suite confirms the incoming signal is invisible to the recipient (rows, state, unread, Activity, public profile), withdrawal, one match per pair, independent unread state, ending for both; 20 pairs pressing Again simultaneously produce exactly 20 matches, and the same test missed matches in 2 of 3 runs with the lock disabled; 7/7 browser journeys including guest intent, crafted-link refusal, server HTML revealing nothing before a match, copy, and quiet ending. Full regression: 43/43 signed-in journeys, guest journey at 320px and 390px, 18/18 unit tests, typecheck and build.

**Second build slice, 13 November 2026:** Continued at Tek's request. Added migrations `20261113150000_calendar_context_and_prompts.sql` and `20261113170000_activity_editing_archive.sql`. **Google Calendar:** separate optional connection on My QR using `calendar.calendarlist.readonly` and `calendar.events.readonly` (narrowest read-only scopes), PKCE and state cookie, grant bound to the starting account; partial grants store nothing; refresh token AES-256-GCM encrypted with a server-only key and not selectable from the database even by its owner; raw events never stored. One matching event saves private “Likely met at” context; several offer a choice; none offers manual entry; edit/remove/Undo; removed context is not re-inferred.
