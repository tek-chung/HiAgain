**Dismiss Undo and text limits, 1 November 2026:** Tek requested undo for dismissed event suggestions and suitable question/answer limits with a word count at the text-box bottom right. Added per-account last-in-first-out dismissal Undo, retained in private demo state. Implementation defaults chosen under Tek's request: all three action prompts/questions and reviewed invitations have a 180-character limit; answers and feedback requests have a 1,500-character limit for both creation and edits. This replaces 100-character prompt fields and previously unbounded answers. Textareas show live words plus character usage/limit at bottom right (also retaining existing Introduction/Notes limits). Character limits are enforced natively and on prototype submission/save; over-limit restored/programmatic drafts are rejected without truncating them. Profile card context is visually clamped to two lines while retaining full content in the underlying invitation/question. The existing one-answer rule is unchanged. Passed 369 local assertions at 320px and 740px, including Undo order/restoration, exact/over limits, edit preservation, counter position and two-line previews. Backend enforcement, real storage and Unicode counting policy remain to implement/validate; no production security claim.
